# Vibe Driven Screensavers

Четыре настоящие заставки macOS в формате `.saver`. Для каждой есть отдельное приложение предпросмотра в Xcode с тем же кодом рисования и анимации. Во время работы не нужны сеть, аккаунты, API-ключи или внешние зависимости.

[English README](README.md) · [Лицензия MIT](LICENSE)

## Что входит

| Заставка | Описание | Ключ проекта |
| --- | --- | --- |
| [Тревожный терминал](Terminal/README.md) | Местное время `ЧЧ:ММ:СС`, сегментные цифры, дискретные шкалы и четыре палитры | `terminal` |
| [Самоиграющий лабиринт](Pacman/README.md) | Пиксельная аркада, четыре разных призрака, случайные связные карты, `GAME OVER` и `YOU WON` | `pacman` |
| [Живой пиксельный город](City/README.md) | Панорама по мотивам Москва-Сити, окна, погода, поезда, машины и часы на станции | `city` |
| [Неоновый квартал](Neon/README.md) | Киберпанковая сцена, анимированные голограммы, поезд, подсветка автомобиля и дым | `neon` |

Галерея находится в [основном README](README.md#the-collection). Все проекты независимы: можно собрать и установить только понравившийся.

## Требования и скачивание

Нужен Mac и **полный Xcode** с SDK macOS. Одних Command Line Tools недостаточно. Минимальная версия в настройках проектов — **macOS 13.0**. Сборка проверена с Xcode 27.0 / SDK macOS 27.0; запуск на macOS 13 и Intel отдельно не проверялся. Релизные модули универсальные: `arm64` и `x86_64`.

После установки один раз откройте Xcode и завершите его первоначальную настройку.

```sh
git clone https://github.com/ThePigeonKing/vibe-driven-screensavers.git
cd vibe-driven-screensavers
```

Все следующие команды выполняются из корня репозитория.

## Сначала предпросмотр

Откройте проект в Xcode, выберите **схему предпросмотра** и **My Mac**, нажмите **Run (`⌘R`)**:

| Проект | Схема для Run | Имя готового модуля |
| --- | --- | --- |
| [Terminal/AlarmTerminal.xcodeproj](Terminal/AlarmTerminal.xcodeproj) | `AlarmTerminalPreview` | `AlarmTerminal.saver` |
| [Pacman/Pacman.xcodeproj](Pacman/Pacman.xcodeproj) | `AutoPacmanPreview` | `AutoPacman.saver` |
| [City/PixelCity.xcodeproj](City/PixelCity.xcodeproj) | `PixelCityPreview` | `PixelCity.saver` |
| [Neon/NeonDistrict.xcodeproj](Neon/NeonDistrict.xcodeproj) | `NeonDistrictPreview` | `NeonDistrict.saver` |

Схема без `Preview` собирает модуль заставки; отдельного запускаемого приложения у неё нет.

У всех предпросмотров окно можно растягивать. `⌘1` — маленький предпросмотр 420×263, `⌘2` — обычное окно, `⌃⌘F` — полный экран. В терминале `⌘3`…`⌘6` меняют палитру; она сохраняется и для установленной заставки. В городе `⌘0` возвращает естественную погоду, `⌘3`/`⌘4`/`⌘5` включают ясную ночь/облачность/дождь для предпросмотра.

## Собрать

```sh
# Все четыре универсальных модуля .saver.
./scripts/build.sh all

# Только один модуль.
./scripts/build.sh neon

# Приложение предпросмотра и его запуск.
./scripts/build.sh neon preview
open build/neon/Build/Products/Debug/NeonDistrictPreview.app
```

Вместо `neon` можно указать `terminal`, `pacman` или `city`; `all preview` собирает все приложения предпросмотра. Скрипты поддерживают `--help`.

Если `xcode-select` указывает на Command Line Tools, скрипты автоматически используют `/Applications/Xcode.app`, когда он установлен. Глобальная настройка developer directory не меняется. Для другого пути задайте `DEVELOPER_DIR`:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build.sh all
```

Результаты находятся в `build/<ключ>/Build/Products/Release/`, например `build/neon/Build/Products/Release/NeonDistrict.saver`. Предпросмотры — в соседней папке `Debug/`. Сборка кнопкой Run в Xcode может использовать собственную папку DerivedData; скрипт установки рассчитан на результаты `scripts/build.sh`.

## Установить и выбрать

Закройте Системные настройки. После сборки:

```sh
./scripts/install.sh all
# Или только одну заставку:
./scripts/install.sh neon
```

Модули копируются в **`~/Library/Screen Savers/`** только для вашей учётной записи, без `sudo`. Скрипт проверяет наличие всех запрошенных сборок и обновляет модули с теми же именами. Он не собирает проекты и не снимает карантин автоматически.

Ручное копирование:

```sh
mkdir -p "$HOME/Library/Screen Savers"
ditto build/neon/Build/Products/Release/NeonDistrict.saver \
  "$HOME/Library/Screen Savers/NeonDistrict.saver"
```

Откройте **Системные настройки**, найдите **Заставка** через поиск и выберите модуль в разделе **Другие**. На новых версиях macOS это **Обои → Заставка**, на старых — отдельный раздел. Проверьте системный полноэкранный предпросмотр. См. [инструкцию Apple](https://support.apple.com/guide/mac-help/change-screen-saver-settings-mchlp1227/mac).

Если после обновления отображается старая версия, закройте и снова откройте Системные настройки; при сохранении проблемы выйдите из учётной записи и войдите обратно. Для удаления выберите другую заставку и перенесите соответствующий `.saver` из этой папки в Корзину.

### Если macOS сообщает о недоверенном источнике

Для локальной разработки подпись отключена; эти сборки не подписаны Developer ID и не нотариализованы. Локально собранный модуль обычно не имеет карантина скачанного файла. Для загруженного модуля сначала используйте [рекомендации Apple](https://support.apple.com/en-us/102445), включая **Конфиденциальность и безопасность → Всё равно открыть**, если этот пункт доступен.

Если вы проверили конкретный модуль и доверяете ему, можно посмотреть атрибуты и убрать только атрибут карантина:

```sh
xattr -lr "$HOME/Library/Screen Savers/NeonDistrict.saver"
xattr -dr com.apple.quarantine "$HOME/Library/Screen Savers/NeonDistrict.saver"
```

Подставьте имя нужного `.saver`. Эта команда не подписывает и не нотариализует модуль.

## Структура и изменения

У каждого проекта в `Terminal/`, `Pacman/`, `City/` и `Neon/` одинаковая структура:

- `Shared/` — сцена, модель анимации и обёртка `ScreenSaverView`;
- `Preview/` — приложение предпросмотра, окно и меню;
- `ScreenSaver/` — метаданные модуля;
- `Tools/` — проверки модели, рендер снимков и кадров;
- `*.xcodeproj/` — две цели и общие схемы Xcode.

В `Neon/Resources/` находится обязательная фоновая иллюстрация и [история её создания](Neon/Resources/ARTWORK.md). В корне: `scripts/` — общие команды, `Tools/VerifySaverBundle.swift` — загрузка модуля для проверки, `docs/` — галерея, `build/` — игнорируемые результаты сборки. Терминал перенесён с корня в `Terminal/` для единой структуры.

Для визуальных изменений редактируйте `Shared/`, смотрите результат через Run и затем пересобирайте `.saver`. Палитры терминала — в `TerminalTheme.swift`; логика игры — в `MazeGame.swift`; погода и транспорт — в `CitySceneModel.swift`; расписания неоновых экранов и поездов — в `NeonAnimationModel.swift`. Файлы `*ArtworkView.swift` отвечают за рисование. [Подробная карта исходников и добавление новой сцены](README.md#customize-or-extend-a-scene).

## Проверки

```sh
./scripts/check.sh all
# Или, например:
./scripts/check.sh pacman
```

Скрипт проверяет границы и интервалы шкал, связность случайных карт, автономные партии, длительную смену погоды и транспорта, анимацию экранов и восстановление после скачков времени. Затем загружает уже собранные Release-модули и проверяет их главный класс. Если модуль ещё не собран, эта часть явно пропускается.

В README каждого проекта описаны дополнительные инструменты для снимков, кадров анимации и замеров. Проверки моделей, загрузка bundle и рисование в памяти не заменяют проверку установленной заставки в системном ScreenSaverEngine. Проверьте маленький предпросмотр, полный экран и выход из сна на своём Mac.
